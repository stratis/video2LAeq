# video2laeq

Υπολογισμός **LAeq**, **LAF10** και **LAF90** από βίντεο (`.mov`, `.mp4` κ.λπ.) που δείχνει
την οθόνη ενός φορητού ηχομέτρου (LCD 7-segment, π.χ. Cadrim). Από κάθε δευτερόλεπτο του
βίντεο διαβάζεται αυτόματα η ένδειξη dB(A) και προκύπτει ένα δείγμα ανά δευτερόλεπτο.

## Εγκατάσταση

Χρειάζεται `ffmpeg` (`brew install ffmpeg`) και [uv](https://docs.astral.sh/uv/).

```bash
cd video2LAeq
uv sync
```

## Χρήση

```bash
# Απλή έξοδος κειμένου
uv run video2laeq "καταγραφή.mov"

# Extended mode: PDF με γράφημα χρονοσειράς, συν CSV με τα δείγματα
uv run video2laeq "καταγραφή.mov" --pdf report.pdf --csv samples.csv

# JSON για scripting
uv run video2laeq "καταγραφή.mov" --json
```

Παράδειγμα εξόδου:

```
Αρχείο:    καταγραφή.mov
Διάρκεια:  04:04
Δείγματα:  239 έγκυρα / 244 σύνολο
LAeq   =  51.0 dB(A)
LAF10  =  53.4 dB(A)
LAF90  =  47.4 dB(A)
Lmin   =  43.9 dB(A)   Lmax =  61.0 dB(A)
```

### Επιλογές

| Επιλογή | Περιγραφή |
|---|---|
| `--pdf FILE` | Αναφορά PDF (ελληνικά) με μεταδεδομένα, πίνακα αποτελεσμάτων και γράφημα dB(A)–χρόνου |
| `--csv FILE` | Δείγματα ανά δευτερόλεπτο: `t_sec, dBA, valid, reason` |
| `--json` | Αποτελέσματα σε JSON αντί για κείμενο |
| `--fps N` | Καρέ που αναλύονται ανά δευτερόλεπτο (default 4). Το δείγμα του δευτερολέπτου είναι η διάμεσος των αναγνώσεων που συμφωνούν μεταξύ τους |
| `--roi X,Y,W,H` | Σταθερή περιοχή της οθόνης LCD (pixels στο καρέ). Παρακάμπτει την αυτόματη ανίχνευση· χρήσιμο μόνο με σταθερή κάμερα |
| `--decimals N\|auto` | Δεκαδικά ψηφία της ένδειξης (default 1). Με `auto` χρησιμοποιείται η υποδιαστολή που εντοπίζεται στην οθόνη |
| `--debug DIR` | Αποθηκεύει για κάθε καρέ το crop της οθόνης, τη δυαδική εικόνα με τα ψηφία που βρέθηκαν και την τιμή στο όνομα του αρχείου (`X` = μη αναγνώσιμο) |

## Πώς δουλεύει

1. **Καρέ**: `ffmpeg` εξάγει `--fps` καρέ ανά δευτερόλεπτο.
2. **Οθόνη**: εντοπίζεται το πορτοκαλί σώμα του οργάνου (HSV) και η LCD προκύπτει από τη
   γεωμετρία του (κεντραρισμένη, ~0.5 πλάτη σώματος κάτω από την κορυφή του). Έτσι δουλεύει
   και με κάμερα χειρός.
3. **Ψηφία**: black-hat μορφολογία αναδεικνύει τα σκούρα segments ανεξάρτητα από φωτισμό,
   διορθώνεται η italic κλίση, τα ψηφία χωρίζονται σε στήλες και κάθε ψηφίο συγκρίνεται με
   πρότυπα 7-segment ίδιου πάχους γραμμής (IoU). Αμφίβολα ψηφία απορρίπτονται αντί να
   μαντεύονται.
4. **Έλεγχοι**: τιμές εκτός 20–140 dB, απομονωμένα άλματα > 15 dB και δευτερόλεπτα με
   ασυνεπείς αναγνώσεις μεταξύ καρέ απορρίπτονται και μετρώνται ως άκυρα.
5. **Μεγέθη**: `LAeq = 10·log10(mean(10^(Li/10)))`, `LAF10` = 90ο εκατοστημόριο,
   `LAF90` = 10ο εκατοστημόριο των έγκυρων δειγμάτων.

> Με ένα δείγμα ανά δευτερόλεπτο τα LAF10/LAF90 είναι προσέγγιση των τιμών που θα έδινε
> συνεχής καταγραφή FAST (125 ms). Το ποσοστό άκυρων δειγμάτων εξαρτάται από τον φωτισμό και
> τις αντανακλάσεις στην οθόνη· σε καλά φωτισμένα πλάνα ξεπερνά το 95%, σε σκοτεινά/με
> αντανακλάσεις μπορεί να πέσει στο 20–50%.

## Αν κάτι δεν διαβάζεται

```bash
uv run video2laeq "καταγραφή.mov" --debug debug/
open debug/frame0_roi.png      # το κόκκινο πλαίσιο πρέπει να περικλείει την LCD
```

- Αν το πλαίσιο είναι λάθος, δώσε το χειροκίνητα με `--roi X,Y,W,H` (μόνο για σταθερή κάμερα).
- Στα `debug/*_X.png` φαίνεται γιατί απέτυχε η ανάγνωση (π.χ. αντανάκλαση πάνω στα ψηφία).
- Για καλύτερα αποτελέσματα: γέμισε το κάδρο με το όργανο, απόφυγε αντανακλάσεις στην LCD,
  κράτα την κάμερα κάθετα στην οθόνη.
